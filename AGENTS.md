# Agent Kaizen: notes for coding agents

A Claude Code plugin: Markdown skills (`skills/*/SKILL.md`), one agent (`agents/`), hooks (`hooks/`), stdlib-only Python and shell scripts (`scripts/`), and starting-point templates (`templates/`). README.md explains the loop; docs/ has the details.

## Commands

Use `python3`, not `python` (which often isn't on PATH).

```
python3 -m unittest discover -s tests      # unit, hook, repo-consistency and privacy tests
shellcheck -S warning hooks/*.sh
claude plugin validate .
```

CI (.github/workflows/ci.yml) also checks that every JSON file parses and that each script answers `--help`.

## Rules

- **Version and changelog:** any change under `skills/`, `agents/`, `hooks/`, `scripts/`, `templates/` or `.claude-plugin/` bumps `version` in `.claude-plugin/plugin.json` and adds a `## x.y.z (date)` entry to CHANGELOG.md. CI enforces this on PRs.
- **Skills:** frontmatter `name` equals the folder name, `description` is quoted, and `disable-model-invocation: true`. Every skill is listed in the README skills table. Tests check all three.
- **Privacy:** no home-directory paths, personal emails or key-like strings in any file git tracks (tests/test_repo.py). Never commit audit reports or transcripts.
- **Scripts:** Python 3.9+, standard library only. `token-audit` must stay zero-token and fast; time it against `git show HEAD:scripts/token-audit` when changing the scan.
- **Prices:** `scripts/pricing.json` is copied by hand from the vendors' pricing pages; update `source.checked` when you change it. Never fill in a price from memory.
- **Assets:** generated by `assets/src/*.py` (teaser, banner title). Change the script and regenerate; don't hand-edit the images. `teaser.gif` stays under 3 MB. `assets/loop.svg` is hand-written SVG with light/dark themes and CSS-only animation.
- **Scratch:** put previews, logs and temporary output in `out/` (git-ignored).
- **Writing:** plain, short sentences; no marketing language. Claims and numbers come from docs/what-we-learned.md or a measured ledger row, never estimates presented as results.
- Don't commit or push unless asked.
